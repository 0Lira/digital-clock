# Digital Clock

Um simples relógio digital implementado com HTML, CSS e JavaScript.

## Visão Geral

Este projeto é um relógio digital básico que exibe a hora atual em um formato interativo no navegador.

## Como Usar

1. Clone este repositório para sua máquina local:
   ```bash
   git clone https://github.com/0Lira/digital-clock.git
   ```
2. Navegue até o diretório do projeto:
   ```bash
   cd digital-clock
   ```
3. Abra o arquivo `index.html` em seu navegador web preferido para ver o relógio em funcionamento.

## Tecnologias Utilizadas

*   HTML
*   CSS
*   JavaScript
